# MotoDrive — сайт мотосалона (учебный проект Web25-2Б, АГПК, 2026)

Тёмный современный сайт мотосалона на русском языке с каталогом, страницами моделей, заявками и админ-панелью.

## Дизайн
- Тёмная тема: глубокий графит/почти чёрный фон, акцент — насыщенный оранжево-красный (жар выхлопа), вторичный акцент — холодный стальной.
- Крупная плотная типографика заголовков, узкие моноширинные подписи для характеристик.
- Карточки моделей с фото, мягкой подсветкой при наведении, аккуратные кнопки.
- Полная адаптивность: телефон и компьютер.

## Страницы
1. **Главная** — крупный заголовок MotoDrive, описание салона, кнопка «Смотреть каталог», блок популярных моделей (3–4 карточки), краткие преимущества.
2. **Каталог** — сетка мотоциклов; поиск по названию и описанию, фильтр по типу (спорт, нейкед, эндуро, круизер, турер), сортировка по цене (дешевле/дороже) и году.
3. **Страница мотоцикла** — крупное фото, цена, год, объём двигателя, мощность, максимальная скорость, тип, описание, кнопка «Оставить заявку» (ведёт на форму с уже выбранной моделью).
4. **Заявка** — имя, телефон, модель (выбор из списка), комментарий. Проверка полей с понятными сообщениями об ошибках, уведомление об успешной отправке.
5. **О проекте** — точные данные: создатель Даниель, главный разработчик Сайфулло, группа Web25-2Б, колледж АГПК, 2026 год.
6. **Админ-панель** — добавление, редактирование, удаление мотоциклов (название, цена, год, объём, мощность, макс. скорость, тип, описание, ссылка на фото) и список полученных заявок с возможностью удаления.
7. **Футер** — «© 2026 MotoDrive | Web25-2Б | АГПК» и ссылки на разделы; общая верхняя навигация на всех страницах.

## Данные
- Начальный набор из 8 реалистичных мотоциклов с характеристиками и фото.
- Все изменения из админ-панели и все заявки сохраняются в браузере (localStorage) и сразу видны в каталоге. Данные хранятся у каждого посетителя локально, общей базы нет — для учебного проекта этого достаточно. При желании позже можно подключить настоящую базу.
- Фотографии мотоциклов сгенерирую как изображения проекта (тёмные студийные снимки), для добавленных вручную моделей используется ссылка на фото.

## Техническая часть
- Маршруты TanStack Router: `/`, `/catalog`, `/moto/$id`, `/request`, `/about`, `/admin`; у каждой свои заголовок и описание для поиска и соцсетей.
- Единый источник данных: модуль каталога с начальными моделями + слой localStorage (мотоциклы, заявки) и хук подписки, чтобы каталог обновлялся после правок в админке.
- Цвета и тени — токены в `src/styles.css`; компоненты используют только семантические классы.
- Валидация формы через zod, уведомления через sonner.
- Общий layout (навигация + футер) в `__root.tsx`.
