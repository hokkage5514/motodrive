# MotoDrive Showcase

Создай современный рабочий веб-сайт мотосалона «MotoDrive» на русском языке для учебного проекта группы Web25-2Б колледжа АГПК (2026 год).

Участники проекта (строго эти данные, без вымышленных лиц):
- Создатель: Даниель
- Главный разработчик: Сайфулло
- Группа: Web25-2Б
- Колледж: АГПК
- Год: 2026

Структура и возможности:
1. Дизайн: стильная тёмная тема для мотосалона, акцентные цвета, адаптивность под мобильные и десктоп, аккуратные карточки и кнопки.
2. Главная страница: заголовок MotoDrive, описание салона, призыв к действию и кнопка перехода в каталог, блок популярных моделей.
3. Каталог мотоциклов: начальный набор реалистичных мотоциклов с фото, ценой, годом, объёмом двигателя и мощностью. Полнотекстовый поиск, фильтрация по типу/классу, сортировка по цене.
4. Отдельная страница мотоцикла: крупное фото, детальные характеристики (включая максимальную скорость), описание, кнопка «Купить» / «Оставить заявку».
5. Форма заявки: имя, телефон, выбранная модель, комментарий; валидация и уведомление об успешной отправке.
6. Страница «О проекте»: блок с точной информацией об авторах (Даниель, Сайфулло, группа Web25-2Б, АГПК, 2026).
7. Админ-панель: добавление, редактирование и удаление мотоциклов (название, цена, характеристики, описание, ссылка на фото) с сохранением в localStorage, чтобы изменения сразу отображались в каталоге, а также список отправленных заявок.
8. Футер: «© 2026 MotoDrive | Web25-2Б | АГПК» и ссылки на разделы.
